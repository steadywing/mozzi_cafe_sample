# 이미지 생성 요청

아래 세 묶음, 총 31장을 만든다. 모든 이미지는 비율 1:1, 1024×1024 PNG다.

1. 메뉴 대표 이미지 17장 → `data/menu_images/`
2. 상품검색 테스트용 고객 사진 8장 → `data/search_images/`
3. 스탬프 쿠폰 테스트 이미지 6장 → `tests/fixtures/images/coupons/`

---

# 1. 메뉴 대표 이미지

`data/menu.json`의 메뉴 17개에 대한 대표 이미지를 만든다. 이 이미지는 메뉴판 표시와 상품검색(이미지 임베딩 유사도 검색)의 기준 이미지로 쓰인다.

## 공통 규칙

- 비율 1:1, 1024×1024 PNG
- 저장 위치: `data/menu_images/{menu_id}.png` (파일명은 아래 표의 `menu_id`와 정확히 같게)
- 상품 1개만 화면 중앙에 배치, 45도 위에서 내려다본 구도
- 배경: 연한 크림색 단색 + 나무 테이블 일부. 17장 모두 같은 배경·조명 유지
- 자연광 느낌의 부드러운 조명, 실사 사진 스타일
- 글자·로고·워터마크·사람 손 넣지 않기
- 그릇·컵: 흰색 무광 도자기로 통일 (아이스 음료는 투명 유리컵)

## 주의할 점

- 상품검색 테스트용이므로 **닮은 메뉴도 구분되게** 만든다.
  - 카페라떼(큰 잔, 라떼아트) / 플랫화이트(작은 잔, 얇은 거품)
  - 인절미 라떼(베이지색) / 흑임자 라떼(회색)
  - 인절미 모찌(노란 콩가루) / 흑임자 모찌(검은 가루)
- 메뉴 설명에 없는 재료(토핑·장식)를 추가하지 않는다.

# 2. 상품검색 테스트용 고객 사진

고객이 매장에서 휴대폰으로 찍은 것처럼 만든다. 메뉴 대표 이미지와 **같은 사진이 되면 안 된다.** 각도·배경·조명을 일부러 다르게 해야 검색 성능을 확인할 수 있다.

## 공통 규칙

- 비율 1:1, 1024×1024 PNG
- 저장 위치: `data/search_images/{파일명}.png`
- 실사 휴대폰 사진 느낌. 배경은 카페 실내·야외 테이블·사무실 책상 등으로 다양하게
- 글자·로고·워터마크 넣지 않기. 사람 손은 일부 사진에만 허용
- 그릇·컵은 메뉴 대표 이미지와 같은 디자인(흰색 무광 도자기, 투명 유리컵)

# 3. 스탬프 쿠폰 테스트 이미지

`data/events.json`과 `data/cafe_docs/07_스탬프_이벤트.md` 규칙에 맞춘 종이 스탬프 쿠폰이다. 상시 적립 제도의 쿠폰 번호와 스탬프 수를 OCR로 읽고 검증하는지 시험한다. 적립 내역 확인은 10개 미만도 가능하며, 아래 혜택 사용 검증은 스탬프 10개를 채운 쿠폰에 적용한다.

## 쿠폰 디자인 (6장 공통)

- 크림색 종이 카드, 위쪽 가운데 "모찌카페 스탬프 적립"
- 오른쪽 위에 쿠폰 번호 `MOCHI-2026-0000` 형식을 또렷한 숫자로 인쇄
- 가운데 2줄 × 5칸 = 동그란 스탬프 칸 10개
- 스탬프는 분홍색 모찌 얼굴 모양 도장
- 아래쪽에 "음료 1잔당 스탬프 1개 · 10개를 모으면 모찌 1개 무료"
- 나무 테이블 위에 놓인 카드를 위에서 찍은 사진, 비율 1:1, 1024×1024 PNG
- 저장 위치: `tests/fixtures/images/coupons/{파일명}.png`

## 이미지 목록

| 파일명 | 쿠폰 번호 | 스탬프 | 그릴 내용 | 기대 검증 결과 |
|---|---|---|---|---|
| coupon_valid_full | MOCHI-2026-0001 | 10개 | 10칸 모두 찍힌 깨끗한 쿠폰 | 혜택 사용 가능 |
| coupon_not_enough | MOCHI-2026-0002 | 6개 | 앞 6칸만 찍힘 | 혜택 사용 불가: 스탬프 부족 |
| coupon_already_used | MOCHI-2026-0003 | 10개 | 10칸 모두 찍힘 | 혜택 사용 불가: 중복 혜택 사용 |
| coupon_over_limit | MOCHI-2026-0004 | 12개 | 10칸 모두 찍히고 칸 밖 여백에 도장 2개 더 | 실패: 허용 개수 초과 |
| coupon_blurry | MOCHI-2026-0005 | 10개 | 심하게 흔들리고 쿠폰 번호 부분이 접혀 번호를 읽을 수 없음 | 실패: 읽기 실패 |
| coupon_unknown_id | MOCHI-2026-9999 | 10개 | 10칸 모두 찍힌 깨끗한 쿠폰 (발급 목록에 없는 번호) | 실패: 잘못된 ID |
